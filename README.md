\# Striver SDE Sheet \[30 Days Challenge]



This repository contains C++ solutions for Striver's SDE Sheet, a curated list of important interview questions for Data Structures and Algorithms preparation.



Link to the SDE Sheet: \[View](https://docs.google.com/document/d/1SM92efk8oDl8nyVw8NHPnbGexTS9W-1gmTEYfEurLWQ/edit)



\## About this Repository



This project is focused on helping learners practice and understand the most important coding interview problems in C++.



The repository is organized by day and topic, making it easier to follow a structured preparation roadmap.



\## Why this repo?



\- C++ solutions for interview-focused DSA problems

\- Organized by day and category

\- Beginner-friendly structure

\- Useful for revision and quick practice

\- Great for learning patterns and logic behind common problems

\## How to Use



1\. Pick a day/topic folder.

2\. Open the relevant file.

3\. Read the problem statement and logic.

4\. Understand the pattern and try to solve it yourself.

5\. Compare with the provided C++ solution.
